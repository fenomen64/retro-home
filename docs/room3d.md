# 3D «игровая комната» — план и решения

Платная (Pro) замена горизонтального консольного режима: комната в 3D, как в MiSide. Телевизор,
геймпады на полу с проводами, шкафы с полками; одна полка — одна консоль; на полке фигурка и коробки игр.
Обычный консольный режим остаётся (бесплатно и как запасной вариант на слабых устройствах).

Макет (2.5D и 3D рядом, все шаги): https://claude.ai/artifact/EixHwnnGY5ok89uN83BBWo — выбран **3D**.

## Решения (закреплены)
- Графика — **3D**, полноценные объекты, не картинки. Движок — **Filament** (возможно, через SceneView), модели — **glTF/GLB из Blender**, Blender управляется Python-скриптами (headless).
- Камера наезжает на выбранную полку, названия на корешках читаются. ◀▶ — рука указывает на игру.
- A — коробку достают и разворачивают обложкой; Y — переворот (обратная сторона: скриншоты + описание); B — назад.
- Все анимации быстрые, кроме запуска игры.
- Коробки разные, в реальных пропорциях: PS1 — тонкий jewel-кейс, PS2 — высокий DVD-бокс, DC — двойной jewel, картриджи — компактные кейсы, GBA — маленький кейс.
- Носитель по типу консоли: дисковые — диск, картриджные — картридж.
- Загрузка по типу консоли: крышка сверху (PS1, DC…), лоток (PS2…), слот сверху (SNES, N64, GBA…); остальные типы добавить по списку систем.
- У каждой консоли своя заставка запуска — придуманная, без чужих логотипов и названий.
- **Запуск:** коробка открывается → достаём носитель → к консоли → вставляем → лампочка, CRT-включение → заставка консоли.
  Камера начинает наезд на телевизор **в момент, когда заставка начинает гаснуть**; когда экран заполнил весь кадр —
  заставка уже полностью ушла в чёрный, и в этот момент запускается эмулятор **без системной анимации**. Видео геймплея не нужно.
- **Возврат из игры:** экран в комнате начинается чёрным, камера отъезжает назад.
- Вариант «затягивание в экран» — отклонён.
- Steam — отдельная вкладка позже (через файлы-списки игр для GameNative / GameHub), не в этом проекте.

## Открытые вопросы (решить на этапе 0)
- Много игр на одной консоли: прокрутка вдоль полки / несколько полок / «ящик».
- Много консолей (20+): несколько шкафов / вторая стена / комнаты-вкладки.
- Стиль и референсы (автор пришлёт картинки).
