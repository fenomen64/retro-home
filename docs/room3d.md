# 3D «игровая комната» — план и решения

Платная (Pro) замена горизонтального консольного режима: комната в 3D, как в MiSide. Телевизор,
геймпады на полу с проводами, шкафы с полками; одна полка — одна консоль; на полке фигурка и коробки игр.
Обычный консольный режим остаётся (бесплатно и как запасной вариант на слабых устройствах).

Макет (2.5D и 3D рядом, все шаги): https://claude.ai/artifact/EixHwnnGY5ok89uN83BBWo — выбран **3D**.

## Решения (закреплены)
- Графика — **3D**, полноценные объекты, не картинки. Движок — **Filament** (возможно, через SceneView), модели — **glTF/GLB из Blender**, Blender управляется Python-скриптами (headless).
- Камера наезжает на выбранную полку, названия на корешках читаются. ◀▶ — рука указывает на игру.
- A — коробку достают и разворачивают обложкой; Y — переворот (обратная сторона: скриншоты + описание); B — назад.
- Все анимации быстрые, кроме запуска игры.
- Коробки разные, в реальных пропорциях: PS1 — тонкий jewel-кейс, PS2 — высокий DVD-бокс, DC — двойной jewel, картриджи — компактные кейсы, GBA — маленький кейс.
- Носитель по типу консоли: дисковые — диск, картриджные — картридж.
- Загрузка по типу консоли: крышка сверху (PS1, DC…), лоток (PS2…), слот сверху (SNES, N64, GBA…); остальные типы добавить по списку систем.
- У каждой консоли своя заставка запуска — придуманная, без чужих логотипов и названий.
- **Запуск:** коробка открывается → достаём носитель → к консоли → вставляем → лампочка, CRT-включение → заставка консоли.
  Камера начинает наезд на телевизор **в момент, когда заставка начинает гаснуть**; когда экран заполнил весь кадр —
  заставка уже полностью ушла в чёрный, и в этот момент запускается эмулятор **без системной анимации**. Видео геймплея не нужно.
- **Возврат из игры:** экран в комнате начинается чёрным, камера отъезжает назад.
- Вариант «затягивание в экран» — отклонён.
- Steam — отдельная вкладка позже (через файлы-списки игр для GameNative / GameHub), не в этом проекте.

## Решения этапа 0 (2026-10-21)
- **Много игр на консоли — полка + ящик.** На полке стоят 12 последних запущенных игр (у новой консоли — первые 12 по алфавиту).
  Последняя позиция на полке — открытый ящик под полкой с надписью «Все игры (N)». В ящике все игры консоли стоят корешками вверх и
  листаются как пластинки: ◀▶ по одной, удержание ускоряет, L/R прыгают по первой букве. A в ящике достаёт коробку так же, как с полки.
- **Много консолей — вторая стена.** Показываем только консоли, где есть игры. Первые ~10 консолей (по порядку из настроек) стоят
  в шкафах у передней стены (там же ТВ), остальные — у задней. Когда ▲▼ уходит за последнюю полку передней стены, камера
  разворачивается на 180° к задней. Если консолей ≤ 10, задняя стена просто декоративная (окно, кровать, ковёр на стене).
- **Стиль — смесь + уголок ПК.** Основа — постсоветская квартира 90-х, плюс письменный стол с ЭЛТ-монитором и системным блоком
  для ПК-игр, RPG Maker/Ren'Py и ScummVM, и придуманные плакаты. Подробно — ниже.

## Стиль комнаты (по референсам автора)
Детская/подростковая комната конца 90-х — начала 2000-х, смесь постсоветской квартиры и американской спальни.
- **Свет:** тёплое солнце из окна с тюлем, мягкие лучи в пыли; вечером — торшер и свечение ЭЛТ. Запечённый свет (этап 2).
- **Пол:** ковёр с восточным узором (бордово-бежевый) поверх линолеума/паркета. Второй ковёр — на стене.
- **Стены:** обои с мелким узором (ромбы, вензеля), розетки старого образца, плинтус.
- **Мебель:** полированная «стенка»/тумба тёмного дерева под ТВ, книжные полки, письменный стол с ЭЛТ-монитором и системным блоком (уголок ПК).
- **ТВ:** выпуклый ЭЛТ 14–21″ в тёмном корпусе, на тумбе; под ним видеомагнитофон и стопка кассет.
- **Детали:** плакаты (только **придуманные** — свои фильмы/группы, без реальных лиц и логотипов), магнитола, бутылка газировки (своя марка), журналы, геймпады с проводами на ковре, рюкзак, растения на подоконнике, батарея, шторы с узором.
- **Беспорядок:** умеренный — пара картриджей, журнал и геймпады на полу; полки с играми аккуратные (корешки должны читаться).
- **Палитра:** тёплое дерево, охра, бордо, бежевый, зелёный растений; холодный только от экрана.
- **Нельзя:** реальные бренды на ТВ, бутылках, плакатах (Toshiba, Coca-Cola, Terminator, Metallica и т. п. — только свои придуманные аналоги).
- **Уголок ПК:** стол у боковой стены, ЭЛТ-монитор, системный блок с лотком CD и дисководом 3,5″, клавиатура, коврик.
  Для систем PC / JoiPlay / ScummVM / Аркада камера едет к столу, а наезд при запуске идёт на монитор, а не на ТВ.

## Мелкие решения (2026-10-21)
- **Портативные (решено: в руках)** (GB, GBC, GBA, GG, NDS, 3DS, PSP, Vita, Switch): приставка лежит на тумбе рядом с ТВ.
  При запуске руки берут её, носитель вставляется в неё, загорается её экран, и наезд идёт на её экран, а не на ТВ.
  Нужны 9 моделей портативных и анимация рук (держат приставку экраном к камере).
- **Аркада (решено):** без автомата. Как в 2000-х играли в эмулятор аркад на компьютере: самописный сборник на CD-R
  «АРКАДЫ 500 в 1» (подписан маркером) в тонком jewel-кейсе, запуск в уголке ПК через лоток системника.
- **Несколько дисков** (PS1, DC, Saturn, PC и др. с `.m3u`/«Disc N»): коробка толще (двойной jewel / fatpack), при запуске берём диск 1.
- **PC Engine:** носитель по расширению файла: `.pce/.sgx` — карточка HuCard в слот спереди, `.cue/.chd/.ccd` — CD в CD-приставку (крышка сверху).
- **Отмены нет (решено):** после START кнопка B ничего не делает до самого запуска эмулятора.

## Тайминги анимаций
Источник — код макета (секунды). «Плавно» = кривая ease-in-out, «разгон» = ease-in, «торможение» = ease-out.

### Навигация
| Действие | Длительность | Как |
|---|---|---|
| Камера к полке / между полками (▲▼, A, B) | 0,4 с (95 % пути) | плавное догоняние цели |
| Разворот камеры к задней стене | 0,7 с | плавно, поворот 180° по дуге |
| Рука переходит к соседней игре (◀▶) | 0,25 с | торможение; выбранная коробка выдвигается на 8 мм |
| Удержание ◀▶ | первый шаг сразу, повтор через 0,35 с, дальше каждые 0,08 с | — |
| Открыть ящик / закрыть | 0,35 с | торможение |
| Листание в ящике (шаг) | 0,12 с | коробка наклоняется на 25° |
| A: достать коробку и развернуть обложкой | 0,45 с | плавно |
| Y: перевернуть коробку | 0,4 с | плавно, поворот 180° |
| B: вернуть коробку на полку | 0,35 с | плавно (обратный ход) |

### Запуск (START), секунды от нажатия
| Время | Что происходит |
|---|---|
| 0,00–1,10 | Коробка открывается (обложка-крышка: 0,40–0,95, поворот на 118°, плавно) |
| 1,10–1,80 | Носитель выходит из коробки (плавно); камера ещё на полке |
| 1,80–2,80 | Носитель летит к консоли, диск поворачивается плашмя; камера едет к консоли |
| 2,00–2,45 | Крышка поднимается / лоток выезжает |
| 2,80–3,15 | Диск ложится (крышка); лоток: 2,80–3,10; слот/картридж: 2,80–3,40 |
| 3,15–3,55 | Крышка закрывается / лоток заезжает |
| 3,45 | Лампочка на консоли: красная → зелёная |
| — | **Портативные:** 1,80–2,30 руки поднимают приставку с тумбы к камере (плавно); 2,30–2,90 носитель входит в слот; 3,45 лампочка; дальше включение и заставка на её экране, наезд на её экран |
| 3,60 | Камера начинает ехать к телевизору (точка «перед ТВ») |
| 3,60–3,95 | Включение кинескопа: белая полоса раскрывается в кадр |
| 3,95–5,40 | Заставка консоли (рисуется: 0–1,1 с, название появляется 1,1–1,6 с) |
| 5,40 | Заставка начинает гаснуть, **камера начинает наезд на экран** |
| 5,40–6,60 | Наезд 1,2 с с разгоном; заставка уходит в чёрный за те же 1,2 с |
| 6,60 | Экран заполнил кадр и полностью чёрный → запуск эмулятора без системной анимации |

Итого запуск ≈ 6,6 с. Видео/игры на ТВ нет (решение выше).

### Возврат из игры
| Время | Что происходит |
|---|---|
| 0,00 | Кадр = чёрный экран ТВ во весь кадр (камера в конце наезда) |
| 0,00–1,20 | Камера отъезжает к общему виду комнаты (торможение); экран ТВ остаётся чёрным |
| 0,60–1,00 | На ТВ проявляется заставка-ожидание лаунчера (RETRO HOME) |
| 1,20 | Управление снова доступно; носитель уже в консоли, коробка уже на полке |
